# useClickOutside

## 描述

`useClickOutside` 是一个用于检测点击元素外部事件的 React Hook。当用户点击指定目标元素外部时触发回调函数，适用于下拉菜单、模态框、弹出层等需要点击外部关闭的场景。

## API

### 函数签名

```ts
function useClickOutside(callback: (event: MouseEvent) => void, options?: UseClickOutsideOptions): void
```

### 参数

| 参数       | 类型                          | 必需 | 说明                 |
| ---------- | ----------------------------- | ---- | -------------------- |
| `callback` | `(event: MouseEvent) => void` | 是   | 点击外部时的回调函数 |
| `options`  | `UseClickOutsideOptions`      | 否   | 配置项               |

### Options

| 参数        | 类型                                                                                 | 默认值    | 说明                                                                   |
| ----------- | ------------------------------------------------------------------------------------ | --------- | ---------------------------------------------------------------------- |
| `eventName` | `'click' \| 'mousedown' \| 'mouseup'`                                                | `'click'` | 监听的事件类型                                                         |
| `target`    | `(() => HTMLElement \| null) \| HTMLElement \| null \| React.RefObject<HTMLElement> \| React.RefObject<null>` | -         | 目标元素，点击外部时会触发回调。支持传入元素、ref 对象或返回元素的函数 |
| `capture`   | `boolean`                                                                            | `false`   | 是否在捕获阶段监听事件                                                 |

## 示例

```ts
import { useClickOutside } from '@f-react-hooks/hooks'
import { useRef, useState, useCallback } from 'react'

export const UseClickOutsideDemo = () => {
    const ref = useRef<HTMLDivElement>(null)
    const [count, setCount] = useState(0)

    useClickOutside(() => {
        setCount(c => c + 1)
    }, { target: ref })

    return (
        <div ref={ref} className="bg-blue-500 text-white p-4 rounded-md cursor-pointer">
            点击次数：{count}
        </div>
    )
}
```
